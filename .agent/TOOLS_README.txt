## Setup PageSpeed API:
1. Go to: https://console.cloud.google.com/
2. Create project → Enable PageSpeed Insights API
3. Create API key
4. Add to .env.local: `NEXT_PUBLIC_PAGESPEED_API_KEY=your_key`
