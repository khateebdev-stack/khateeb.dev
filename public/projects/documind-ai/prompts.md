## 4. AI Assistant Prompts (For Building the Project)
*Copy-paste these into ChatGPT/Claude to help you write the code.*

### **A. Setup & Architecture**
> "Act as a Senior Next.js Architect. I am building a SaaS called 'DocuMind AI'. It analyzes PDFs using OpenAI. Please set up the project structure for me. I need a Next.js 14 App Router project with TypeScript, Tailwind CSS, and Shadcn UI. Create the folder structure for: `components`, `lib` (for AI logic), `app` (routes), and `db` (Prisma). Explain your choices."

### **B. The PDF Parsing Logic (Backend)**
> "I need a Node.js function to extract text from a PDF file. I am using `pdf-parse`. The function should take a `Buffer` as input and return a clean string. It should also handle errors. Write the code in TypeScript. Also, suggest how to 'chunk' this text into smaller pieces for the Vector Database (Pinecone)."

### **C. The AI Analysis Prompt (The Brain)**
> "I need a System Prompt for GPT-4. The goal is to analyze a legal contract. The user will provide the contract text. You must output a JSON object with this structure: `{ risks: [{ clause: string, explanation: string, severity: 'high'|'medium'|'low' }], summary: string, score: number }`. Write the prompt to be strict and protective of the freelancer."

### **D. The Frontend Component (The UI)**
> "Write a React component called `RiskCard`. It takes a prop `risk` which has `{ title, description, severity }`. If severity is 'high', the border should be red. If 'medium', yellow. It should have an 'Expand' button to show the full description. Use Tailwind CSS for styling and Lucide React for icons."

### **E. The Database Schema**
> "Write a Prisma Schema for this SaaS. I need models for: `User` (with email, subscriptionStatus), `Document` (belongs to User, has a status 'pending'|'completed', and a JSON field for the analysis result), and `Subscription` (for Stripe). Ensure proper relations."
