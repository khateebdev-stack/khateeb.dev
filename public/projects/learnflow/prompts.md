## 4. AI Assistant Prompts (For Building the Project)
*Copy-paste these into ChatGPT/Claude to help you write the code.*

### **A. Setup & Architecture**
> "Act as a Senior Next.js Developer. I am building a Gamified LMS called 'LearnFlow'. Tech stack: Next.js 14, Prisma (Postgres), Clerk (Auth), and Stripe. Please create the folder structure. I need a `(dashboard)` layout for the student area and a `(teacher)` layout for the creator mode. Explain how to protect the teacher routes."

### **B. The Database Schema (Prisma)**
> "Write a Prisma Schema for this LMS. I need models for: `Course`, `Category`, `Chapter`, `Lesson` (with fields for videoUrl and position), `UserProgress` (tracking isCompleted for each lesson), and `Purchase`. **Crucial:** Add a `Quiz` model related to Lesson with `Question` and `Option` models."

### **C. The Video Player Logic (Mux)**
> "I need a React component for the Video Player using `@mux/mux-player-react`. It should take a `chapterId` and `nextChapterId`. When the video ends (`onEnded`), it should: 1. Call a Server Action to mark the chapter as complete. 2. Trigger a confetti animation. 3. Show a button to play the next chapter."

### **D. The Progress Calculation**
> "Write a utility function in TypeScript to calculate the percentage progress of a course for a specific user. It should take `userId` and `courseId`, query the database for total published chapters, count how many `UserProgress` records exist for that course, and return a number (0-100)."

### **E. The Certificate Generator (PDF)**
> "I need a Next.js API route that generates a PDF certificate. Use `jspdf` or `react-pdf`. It should take the user's name and course title. It needs to load a custom font and a background image template, then draw the text centered on top. Return the PDF stream to the client."
