## 4. AI Assistant Prompts (For Building the Project)
*Copy-paste these into ChatGPT/Claude to help you write the code.*

### **A. Setup & Architecture**
> "Act as a Senior Full Stack Developer. I am building a Telemedicine app called 'HealthStream'. Tech stack: Next.js 14, Supabase (Postgres), LiveKit (Video), and Stripe. Please create the folder structure. I need a 'monorepo' style structure within Next.js. Separate `(patient)` and `(doctor)` route groups. Explain how to handle the 'Waiting Room' logic."

### **B. The Database Schema (Supabase)**
> "Write a Supabase SQL schema for this app. Tables: `profiles` (linked to auth.users, with role 'doctor'|'patient'), `appointments` (time, status, doctor_id, patient_id), `medical_records` (encrypted text). **Crucial:** Write the Row Level Security (RLS) policies so that patients can ONLY see their own records, but doctors can see records of patients they have appointments with."

### **C. The Video Component (LiveKit)**
> "I need a React component for the Video Room using `@livekit/components-react`. It should handle: connecting to the room using a token, rendering the 'VideoGrid', and showing a 'ControlBar' (Mute/Video/End). It must be responsive (mobile friendly). Write the code in TypeScript."

### **D. The Booking Logic**
> "Write a Next.js Server Action called `bookAppointment`. It should: 1. Check if the doctor is available at that time (prevent double booking). 2. Create a Stripe Payment Intent. 3. Return the `clientSecret` to the frontend. Handle race conditions using a database transaction."

### **E. The Prescription PDF Generator**
> "I need a function to generate a PDF prescription. Use `react-pdf/renderer`. It should take a `Prescription` object (doctor name, patient name, meds list, date) and render a professional-looking medical PDF. It should include a placeholder image for the doctor's signature."
